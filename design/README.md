# Events Booking — утверждённые макеты фронтенда

Это эталон дизайна для фронтенда. Страницы должны выглядеть **точь в точь** как утверждённые на канвасе макеты. Не придумывай новый дизайн.

## Что внутри

```
design/
├── README.md        — этот файл: правила и карта страниц
├── tokens.css       — цвета, шрифты, тени, радиусы, классы стекла и hover-превью
├── logo.svg         — знак E (не менять)
├── canvas.json      — раскладка канваса (порядок и название досок)
├── pages/           — 17 утверждённых макетов .dc.html (эталон, см. «Важно» ниже)
└── assets/
    └── auth-landscape.jpg  — пейзаж: гора, озеро, цветущая сакура (фон экрана входа)
```

## Важно: .dc.html — это эталон, а не код

Файлы в `pages/` работают только внутри канваса (`<x-dc>`, `support.js`, `DCLogic`). Открыть их напрямую в браузере или запустить как сайт нельзя. Их нужно **переписать на React** (Vite + TypeScript), используя значения из этой папки:

1. Открой нужный `pages/*.dc.html` и возьми разметку, тексты и расположение блоков.
2. Подключи `tokens.css` и используй переменные (`var(--ink)`, `var(--card-shadow)` и т. д.), а не свои значения.
3. Логотип бери из `logo.svg` (или скопируй ту же разметку в компонент). Логотип менять нельзя.
4. Фото в макетах — заглушки. Для реальных данных используй API или файлы из `assets/`.
5. Цвета, шрифты и отступы сверяй с макетом. Если значения нет в `tokens.css`, сначала посмотри в `pages/`.

## Правила

- **Утверждённый стиль**: фон `--bg-gradient`, карточки `--card` с `--card-shadow`, стеклянные окна `.glass`, Fraunces для заголовков, Inter для текста.
- **Hover-превью (вариант A, 2 секунды)**: предпросмотр открывается через **2 секунды** наведения. Уход курсора закрывает его за **200 мс**. Фото занимает верхнюю часть (`object-position: 50% 22%`). Размытие и градиент описания занимают нижние 62%. Значения в `tokens.css`, классы `.hover-preview-*`. Не возвращать 3 секунды: заголовок доски `R-hover` ещё говорит «3 с», но правило уже 2 с.
- **Избранное**: сердце ♡ на плитках (`aria-pressed`, `aria-label="Добавить в избранное"`). При нажатии показывается подтверждение (toast из `P-modals`).
- **Экран входа и регистрации** (`S-auth`): фон — `assets/auth-landscape.jpg` (`object-fit: cover`). В центре полупрозрачное окно (`.glass`) со случайной цитатой. Цитаты выбираются в `renderVals` из пяти записей: Пикассо, ван Гог, Матисс, Роден, да Винчи. Цитата Микеланджело снята: её авторство не подтверждено первоисточником. Цитату Родена ("Я беру глыбу мрамора…") популярные сборники приписывают ему, но первоисточник не найден, поэтому её стоит заменить на подтверждённую. Переводы сделаны при подготовке.
- **Кнопки**: основная — `.btn-primary` (тёмная `#16201E`), навигационные — `.btn-pill`.
- **Не добавлять** новые цвета, тени, скругления и шрифты, которых нет в `tokens.css`. Если нужного нет, спроси или найди в `pages/`.

## Источник и версия

Файлы в `pages/` синхронизированы с живым канвасом. В папке только утверждённые макеты: 17 досок. Тестовые концепции A, B, C и справочные Main и N-logo сюда не входят (знак — в `logo.svg`). Если на канвасе что-то поменяли, сверь изменения в `pages/` перед работой.
